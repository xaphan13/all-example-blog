AmiaBlog — это простая блог-система, в которой главное — простота, настраиваемость и скорость. Для контента используется Markdown, для поиска — SQLite в памяти, а поддержка i18n встроена из коробки.

## Возможности

### Контент и написание постов
- Поддержка Markdown: пишите посты в Markdown с метаданными в YAML frontmatter
- Подсветка синтаксиса: встроенный highlight.js с автоматической загрузкой языковых пакетов
- Расширения Markdown: поддержка сносок и других расширений Markdown

### Дизайн и UX
- Настраиваемая цветовая схема: выберите любой HEX-цвет для темы блога, полная палитра будет сгенерирована автоматически
- Тёмный/светлый режим: переключайтесь автоматически или вручную фиксируйте `dark` или `light` — выбор за вами
- Адаптивный дизайн: работает без проблем на... практически всём (но только не на IE6, пожалуйста)
- Material Design You: интерфейс Material Design You на MDUIv2

### Производительность
- Возможность генерации статического сайта: есть возможность превратить ваш экземпляр AmiaBlog в статический сайт
- Высокопроизводительный поиск: база данных SQLite в памяти для молниеносных запросов
- Нечёткий поиск: токенизатор jieba-fast для более точных результатов нечёткого поиска
- Несколько способов поиска: выбирайте между `fullmatch` (точный, лучше производительность) или `jieba` (по токенам, лучше точность)
- Автоматическая горячая перезагрузка: автоматическая перезагрузка постов при изменении файлов с помощью событий файловой системы watchdog

### Настройка
- Конфигурация в одном файле: все настройки в одном файле `config.json`
- I18n: встроенная поддержка английского и упрощённого китайского (легко расширить; присылайте PR, если хотите добавить больше языков!)
- RSS-лента: автоматическая генерация RSS-ленты
- Cloudflare Analytics: простая интеграция с Cloudflare Analytics
- Копирайт в подвале: гибкие варианты отображения авторских прав / лицензии

### Технологический стек
- FastAPI: современный Python веб-фреймворк с автоматической документацией OpenAPI
- Jinja2: гибкая и безопасная система шаблонов с кэшированием
- UV: молниеносно быстрый и надёжный менеджер зависимостей
- Pydantic: простая валидация данных
- Watchdog: мониторинг событий файловой системы для автоматической горячей перезагрузки

## Быстрый старт

### Требования
- Python 3.11 или выше (тестировалось только на 3.11.4, может работать на более старых версиях — пробуйте сами)
- Менеджер пакетов [UV](https://github.com/astral-sh/uv)

### Установка

1. Клонируйте репозиторий
   ```bash
   git clone https://github.com/0x24a/AmiaBlog.git
   cd AmiaBlog
   ```

2. Установите зависимости
   ```bash
   uv sync
   ```

3. Настройте свой блог
   Отредактируйте `config.json` с вашими настройками (см. [Конфигурация](/docs/configuration.md)). Файл уже содержит значения по умолчанию, которые можно изменить.

4. **Напишите свой первый пост**
   Создайте Markdown-файл в директории `posts/`. См. [Написание постов](/docs/writing-posts.md).

5. **Запустите сервер**
   ```bash
   uv run uvicorn main:app --host 0.0.0.0 --port 8000
   ```
   Ваш блог будет доступен по адресу http://localhost:8000

## Развёртывание

### Развёртывание в продакшене

Для продакшена рекомендуется использовать Gunicorn с Uvicorn-воркерами:
```bash
uv run gunicorn main:app -w 4 -k uvicorn.workers.UvicornWorker -b 0.0.0.0:8000
```

### Возможность генерации статического сайта

Чтобы превратить ваш экземпляр AmiaBlog в статический сайт, используйте команду `staticify`:
```bash
uv run staticify.py --destination dist/
```
Это сгенерирует статический сайт в директории `dist/`.
Для дополнительной информации см. [Генерация статического сайта](/docs/static-site-generation.md).

1. Сделайте форк и клонируйте репозиторий

   ```bash

   ```

### Рекомендации

- Стиль кода: используйте [Black](https://github.com/psf/black) для форматирования кода
- Сообщения коммитов: следуйте [Conventional Commits](https://www.conventionalcommits.org/)
- Интернационализация: при переводе используйте плейсхолдеры форматирования ключевых слов, если в i18n-термине 2+ плейсхолдера, так как порядок слов может отличаться в зависимости от языка
- Документация: обновляйте соответствующую документацию
