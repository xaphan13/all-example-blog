# Карта проекта

## Назначение проекта

Минимальное веб-приложение на `FastAPI`, демонстрирующее серверный рендеринг HTML через `Jinja2` и стилизацию через `Tailwind CSS` (CDN). Проект создан как учебный/демонстрационный каркас: основной акцент сделан не на объёме функциональности, а на чистой, масштабируемой структуре backend-приложения, пригодной для использования в качестве отправной точки реального сервиса.

Приложение отдаёт две HTML-страницы (`/` и `/about`) и один JSON-эндпоинт (`/api/ping`). Архитектура разделена на слои: точка входа, агрегация маршрутов, инфраструктурный слой `core/`, роутеры, шаблоны и статика.

### Описание файлов и модулей

| Файл / модуль | Ответственность |
|---|---|
| `main.py` | Создаёт экземпляр `FastAPI` через фабрику `create_app()`, монтирует статику, подключает корневой роутер, запускает `uvicorn`. Глобальный `app` используется как ASGI-callable. |
| `router.py` | Единая точка агрегации роутеров. Импортирует `routers.pages` и `routers.api`, объединяет их в один `APIRouter`, который затем подключается в `main.py`. |
| `core/config.py` | Класс `Settings` на `pydantic-settings`. Читает переменные окружения и `.env`, валидирует типы, предоставляет единый объект `settings`. Определяет `BASE_DIR`, `app_name`, `debug`, `host`, `port`, пути к статике и шаблонам. |
| `core/templating.py` | Инициализирует `Jinja2Templates` на основе `settings.templates_dir`, регистрирует глобальную переменную `app_name` для всех шаблонов. |
| `routers/pages.py` | Роутер HTML-страниц. Эндпоинты `/` и `/about` рендерят шаблоны через `templates.TemplateResponse(...)`. Содержит минимальную встроенную логику данных (`features`). |
| `routers/api.py` | Роутер JSON API с префиксом `/api` и тегом `api`. Содержит эндпоинт `/api/ping`, возвращающий `{"status": "ok", "message": "pong"}`. |
| `templates/base.html` | Базовый layout: `<head>`, подключение Tailwind CDN, собственного CSS, JS, навигация и футер через `{% include %}`. Определяет блоки `title` и `content`. |
| `templates/pages/index.html` | Главная страница. Расширяет `base.html`, выводит список `features` и кнопку для вызова `/api/ping`. |
| `templates/pages/about.html` | Страница "О проекте". Расширяет `base.html`, выводит описание и структуру проекта. |
| `templates/partials/navbar.html` | Повторяющийся компонент навигации, используется в `base.html`. |
| `templates/partials/footer.html` | Повторяющийся компонент подвала, используется в `base.html`. |
| `static/css/style.css` | Небольшой пользовательский CSS: глобальный стиль для `<code>`. |
| `static/js/main.js` | Клиентский обработчик кнопки `#ping-btn`: выполняет `fetch('/api/ping')` и отображает результат. |
| `Dockerfile` | Собирает образ на `python:3.12-slim`, устанавливает зависимости, копирует код, запускает `python main.py` на порту `8000`. |
| `compose.yaml` | Описывает сервис `app` с внешней сетью `internal`; порты наружу не пробрасываются. |

## Внешние зависимости и их роль

### Python-зависимости (`requirements.txt`)

| Зависимость | Версия | Роль |
|---|---|---|
| `fastapi` | `0.137.0` | Асинхронный веб-фреймворк, роутинг, валидация, генерация OpenAPI/Swagger. |
| `uvicorn[standard]` | `0.49.0` | ASGI-сервер. Вариант `[standard]` добавляет `uvloop`, `httptools`, `watchfiles` для перезагрузки и производительности. |
| `jinja2` | `3.1.6` | Шаблонизатор для серверного рендеринга HTML. |
| `pydantic-settings` | `2.14.1` | Управление конфигурацией через переменные окружения и `.env` с валидацией типов. |
| `python-multipart` | `0.0.32` | Парсинг `multipart/form-data`, необходимый FastAPI для работы с HTML-формами. |

### Внешние сервисы и ресурсы

| Ресурс | Роль | Примечание |
|---|---|---|
| Tailwind CSS CDN (`https://cdn.tailwindcss.com`) | Поставка CSS-утилит в браузер без локальной сборки. | Используется только для демонстрации; в продакшене рекомендуется локальная сборка. |
| Docker / Docker Compose | Контейнеризация и локальное развёртывание. | `compose.yaml` использует внешнюю сеть `internal`, порт наружу не экспонируется. |

### Отсутствующие зависимости

- **База данных**: не используется.
- **Брокер сообщений**: не используется.
- **Сторонние API**: не используются (кроме CDN Tailwind).
- **Кэш**: не используется.
- **Система аутентификации / авторизации**: не реализована.
